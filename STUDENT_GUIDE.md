# Student guide

1. Sign in at `/student/login`.
2. Open an assigned assessment and read the instructions.
3. Run the system check and grant camera, microphone, and screen-sharing permissions.
4. Start only after every required check is ready.
5. Answer one question at a time. Selecting **Submit & next** locks the answer.
6. Keep the browser tab open and permissions active.
7. At the deadline, the server stops accepting answers and can automatically submit the attempt.
8. Results appear according to the test's release policy.

If recording stops, follow the on-screen warning and contact AS Code Tech according to the course support process. Do not refresh during an active assessment unless instructed.
